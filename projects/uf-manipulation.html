Robotics · UF 2025

Learning-Based Robotic Manipulation

I trained SmolVLA to pick a requested colored block and place it at the center of a coaster, then built the ROS2 pipeline to run it on an SO-101 arm.

Demonstrations

Project details

  • I collected 200 demonstrations total across red, blue, and purple blocks using the SO-101 leader–follower system and trained a SmolVLA vision-language-action policy with LeRobot.
  • I wrote ROS2 nodes to collect camera images and the LLM’s task instruction, send them to the trained policy, and execute the returned actions on the arm.
  • The task language specified which colored block to pick up and place at the center of a coaster.
  • On hardware, the arm could select between red and blue blocks. Target selection became less reliable when purple blocks were included.

System architecture

For the UF Autonomous Robots course, I connected a user’s language request to physical block placement. LeRobot handled demonstration collection and SmolVLA training. I built the ROS2 deployment nodes that passed camera images and task language to the trained policy and used its predicted actions to move the follower arm.

Language selects the target

A user could request a red, blue, or purple block. The LLM produced the task instruction that was passed to SmolVLA alongside the camera images. That language input told the policy which block the user wanted.

The visual setting and required movement were similar across the tasks: select a block, pick it up, and place it at the coaster’s center. The instruction distinguished the requested color, while the VLA policy predicted the robot actions.

Collecting and using demonstrations

I used the SO-101 leader–follower system to demonstrate the pick-and-place motion, collecting synchronized camera observations and robot actions with LeRobot. The dataset contained 200 demonstrations in total across the three block colors. I used those demonstrations to train SmolVLA for the placement task.

During deployment, my ROS2 nodes collected the images and LLM output, sent those inputs to the trained VLA policy, and took the returned actions through to arm execution.

Hardware results and limitations

When the scene contained only red and blue blocks, the arm could distinguish between them and pick up the requested color. When purple blocks were included, selecting the requested block became harder. This remained an unresolved limitation of the project.

A next experiment would be to train an object detector, such as YOLO, to distinguish the block colors and test whether explicit detections improve target selection. I did not implement or evaluate that extension.
