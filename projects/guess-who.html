Robotics · Science Fair 2019–2020

Guess Who Robot

Open-source robotic arm controlled by a Raspberry Pi to play the board game Guess Who using Python.

Demonstrations

Project details

  • Programmed a Raspberry Pi in Python to run game logic for Guess Who.
  • Arm physically interacts with the game board, flipping character panels in response to game state.

System architecture

This project connects a symbolic guessing game to a physical board. A Raspberry Pi runs the Python game logic, and an open-source robotic arm uses a printed extension to flip character panels. The key connection is the mapping from an eliminated character to a specific board position and motion sequence.

Representing the game

The game stores 24 characters and their attributes, then maintains a list of remaining candidates as questions are answered. The computer selects from questions that can still divide the remaining candidates. When few candidates remain, or questions run out, it moves to guessing a character.

The same candidate-elimination step supplies the names of panels that should be lowered. This gives the software a clean transition from game rules to physical actions: first determine which characters are ruled out, then operate their board positions.

From a character name to a board position

A dictionary maps each character name to one of the board’s A1–D6 positions. Each position selects stored approach and contact poses for the arm. The position routines account for the different locations on the board rather than computing a new inverse-kinematics solution for every move.

A motion helper interpolates between the previous joint pose and the requested pose, then sends servo commands through an Adafruit controller. After operating a panel, the arm returns to its home pose before the next board action.

Physical integration and testing

The arm’s printed extension gives it a way to interact with the character panels. The development code includes manual joint-angle and board-position tools for establishing the motions used by each panel routine.

The archived source currently opens in manual panel-position testing mode. It also contains the game logic and the calls connecting eliminated characters to the panel routines.
