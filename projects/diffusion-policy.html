Diffusion Policy Training

I collected demonstrations, trained LeRobot diffusion policies, and deployed them on the Unitree H1-2 through a Python–Java/ROS2 connection.

Project details

  • I used the existing VR teleoperation setup to collect demonstrations and trained manipulation behaviors with LeRobot’s diffusion-policy framework.
  • I connected the Python learning code to the Java robot-control software through ROS2, then deployed the policies on the Unitree H1-2.
  • This was my May–August 2025 IHMC internship. The GR00T lever-turning pipeline came from a separate internship in 2026.

System architecture

This internship focused on learning manipulation behaviors for the Unitree H1-2. I used an existing VR teleoperation setup to collect demonstrations, trained policies with LeRobot, and connected the resulting Python inference code to IHMC’s Java robot-control software.

Demonstrations and policy training

An operator demonstrated manipulation through the existing VR teleoperation setup. I collected those demonstrations and used LeRobot’s diffusion-policy framework to train the behavior. I then deployed the trained policies on the physical H1-2 through the Python–Java integration.

Connecting learning code to robot control

The learning code ran in Python, while IHMC’s robot-control software ran in Java. I connected those components through ROS2 to carry the policy’s output into the existing robot-control system. The video above shows the manipulation work from this internship.
