Animatronic Gator Head

I programmed the eyes, eyebrows, and mouth of our team’s animatronic gator, coordinating servo motion and an audio-reactive jaw.

Demonstrations

Project details

  • I wrote the embedded code to coordinate the jaw, eyes, and eyebrows using Arduino and PCA9685 servo control.
  • I built CSV animation export and playback to turn motion sequences into coordinated servo movement.
  • I mapped audio amplitude to jaw motion using FFT analysis so the gator could appear to talk.
  • I connected the animation and audio code to the embedded controllers. Seeing the mechanisms move together made programming physical systems especially exciting to me.

System architecture

The gator’s face uses coordinated jaw, eye, and eyebrow motion. I worked on the software and electrical interfaces that turn authored expressions into servo commands. Manual control and CSV playback share the desktop-to-controller path shown below.

Authoring and playing expressions

Manual control and CSV sequences

The PySide6 desktop application exposes jaw, eye, and eyebrow controls. I can pose those channels manually and append the current values, together with a dwell time, to a CSV sequence. Each playback row describes one set of channel values and how long to hold it.

Keeping the interface responsive

Sequence playback runs in a Qt worker thread. Each step updates the interface preview and feeds a separate serial-command queue. Keeping playback and serial writes outside the main GUI loop lets the interface remain responsive while an expression plays.

From channel values to servo motion

The desktop application sends a newline-terminated, comma-separated triple of jaw, eye, and eyebrow values over USB serial. The Arduino firmware parses the line, clamps the values, and maps them to servo pulses through a PCA9685 driver over I²C.

The driver produces 50 Hz PWM signals for the jaw, eyes, and two eyebrow servos. A single logical eyebrow value controls the paired outputs, so the animation interface describes facial motion without requiring a separate value for every physical servo.

Audio-reactive jaw motion

I also implemented audio-reactive jaw movement using FFT-based audio analysis. Mapping audio amplitude to jaw motion let the gator appear to talk, alongside its programmed eye and eyebrow expressions. This was a separate behavior from the manual and CSV control path shown in the diagram.
