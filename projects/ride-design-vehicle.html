Project details

  • Our TPED team built an inverted dark ride prototype with a vehicle suspended beneath the track. I worked on its software and electrical integration.
  • I wrote the WiFi communication layer using Mosquitto MQTT to coordinate the vehicle, track systems, and central server.
  • I wrote the sensor-sequencing code, using IR beam-break sensors for trigger detection. I helped with track actuation, which another student led, including switch tracks, turntables, and the motorized drop track.
  • The system supported manual and autonomous subsystem control. As a captain, I suggested subsystem meetings and helped introduce full-group design reviews every fourth meeting; one review surfaced a vehicle-size issue affecting turns.

System architecture

Our team built an inverted dark ride prototype with a vehicle suspended below the track. Vehicle motion, track mechanisms, and sensors had to work together. I wrote the MQTT communication and sensor-sequencing code and worked on the software/electrical integration.

Communication between subsystems

The vehicle and track systems exchange messages through an MQTT broker. Sensor events, vehicle commands, and track commands have separate roles in that communication. The central Python controller uses those events to coordinate the ride sequence, while operator controls support manual and automatic operation.

This structure lets each subsystem handle its local hardware while the ride logic coordinates their behavior. My work covered the communication layer that connected those parts and the code that interpreted the sensor sequence.

Turning sensor events into ride actions

IR beam-break sensors identify discrete trigger points along the track. The sequencing code uses those events to select the next action, such as changing vehicle motion or requesting a switch, turntable, or drop-track operation. The videos show the physical prototype, vehicle yaw, and drop-track operation.

Integrating the team’s work

I supported the track-actuation work, which another student led. As a captain, I suggested subsystem meetings and helped introduce full-group design reviews every fourth meeting. One review surfaced a vehicle-size issue affecting turns. Those reviews gave the team a place to discuss interactions between mechanical dimensions, electrical integration, and software sequencing.
