Research · IHMC 2023

VR Robot Controls

Custom VR interaction systems for controlling IHMC's humanoid robots — camera bounding boxes, radial menus, arm/hand control.

Demonstrations

Project details

  • Built a movable camera bounding box for Blackfly projections so operators can reframe views without leaving VR.
  • Designed a radial menu triggered by controller proximity to robot hands — eliminates need to exit VR for pose changes.
  • Extended locomotion controls for remote teleoperation of IHMC's humanoid robot platform.

Operator interaction overview

This work focused on the interfaces an operator uses while teleoperating IHMC’s humanoid robots. I added camera-view interaction, hand-pose selection, and locomotion-control features within the existing VR control environment.

Reframing the camera view

I built a movable bounding box for Blackfly camera projections. It lets an operator adjust the framing of a camera view while remaining in the VR interface. The VR View demonstration shows the operator interacting with the projected view.

Selecting hand poses in VR

The radial menu is triggered by bringing a controller near the robot’s hands. That keeps pose selection close to the part of the robot being controlled and lets the operator choose hand poses within VR. I designed the menu interaction and connected it to the control interface.

Locomotion controls

I also extended the locomotion controls used for remote humanoid teleoperation. The existing robot-control software handled the robot platform; my work focused on the operator-facing interactions. The demonstrations above show the interface features in use.
