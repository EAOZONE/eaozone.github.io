Research · IHMC 2024

Motion Capture System

Java pipeline mapping full-body pose from an 8-camera Blackfly MoCap rig to three different robot platforms.

Demonstrations

Project details

  • I used Captury pose data from an eight-camera Blackfly setup to drive Psyonic Ability Hands, Franka arms, and IHMC’s Nadia humanoid.
  • Extended system to drive IHMC's Nadia full humanoid robot in collaboration with a senior researcher.

System architecture

The project connected an eight-camera motion-capture setup to robot control. Captury supplied tracked human poses; my Java integration mapped that information into commands for robotic systems. The diagram focuses on the Psyonic hand-control path.

Tracking and retargeting

The Java application connects to the Captury tracking system, acquires the tracked actor, and reads local joint rotations through the existing Captury interface. The motion-capture system performs the tracking; the integration work begins with the resulting pose data.

For the hands, the mapping combines tracked finger rotations into commands for the left and right Psyonic Ability Hands. Thumb motion uses a different mapping from the other fingers. Human finger motion and robotic-hand actuation do not share an identical representation, so that conversion is an explicit part of the pipeline.

Conditioning the hand commands

The hand-control path includes smoothing, a deadband, and joint limits. Smoothing reduces changes between successive commands; the deadband suppresses small variations; limits bound the requested finger angles. These adjustments are applied according to the finger mapping, rather than treating every tracked joint identically.

The resulting commands pass through IHMC’s existing Ability Hand Bluetooth interface. Runtime variables support adjustment of the mapping and filtering parameters while observing the hand response.

From hands to arms and a humanoid

The project’s demonstrations include Psyonic hands, Franka arms, and the Nadia humanoid. I extended the full-body integration to Nadia in collaboration with a senior researcher. The videos above show the hand, arm, and humanoid demonstrations.
